Exploratory Data Analysis (EDA)

📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) using Python. The main objective is to understand the dataset, identify patterns and relationships, detect missing values and outliers, and extract meaningful insights from the data.

🛠️ Technologies & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

🔍 EDA Process

The analysis includes:

- Data loading
- Understanding the dataset
- Data cleaning
- Handling missing values
- Checking duplicate values
- Descriptive statistics
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Data visualization
- Identifying patterns and trends
- Extracting insights

📂 Files

- "Exploratory_data_analysis.ipynb" — Jupyter Notebook containing the complete EDA analysis.

- Dataset-laptopPrice.csv

📊 Visualizations

The project uses charts and plots to understand the data, including:

- Histograms
- Bar charts
- Count plots
- Box plots
- Scatter plots
- Correlation heatmaps

🎯 Objective

The objective of this project is to practice data analysis and visualization techniques and develop a better understanding of datasets using Python.
